# PawPals Pet Clinic PWA

A fast, installable progressive web app for PawPals Pet Clinic. Browse services and book appointments — even offline.

## Tech Stack
- Vite (vanilla JS)
- ESLint + Prettier
- (coming) Service Worker, IndexedDB, Dark mode

## Getting Started
\`\`\`bash
npm install
npm run dev
\`\`\`

## Scripts
- `npm run dev` — start dev server
- `npm run build` — production build
- `npm run preview` — preview build
- `npm run lint` — run ESLint
